# 用手机远程操控 Codex：离开电脑也能盯住任务

> 原文链接：[https://www.sz003.com/jiaocheng/2629](https://www.sz003.com/jiaocheng/2629)

Codex 现在有手机端了，Android 和 iOS 都支持。在手机上发消息，就能操作电脑上的 Codex。

逻辑不复杂。电脑上的 Codex 在跑，手机连过去，人离开电脑也能查看和回复，审批和调整任务。把 ChatGPT App 更新到最新版，进去选连接电脑上的 Codex 就行。

连上之后能干什么

任务真的还在电脑上跑，这点先记住。文件和依赖都留在原机器上，凭据和权限也一样，本地配置同样留在原处，手机只是个遥控器。

能遥控的范围不小。正在跑的线程和任务状态能看，阶段性的输出能看，终端日志和截图能看，diff 和测试结果也能读。它停下来问你问题，你直接回。需要人工确认的命令和网络访问，手机上点批准或者拒绝。想改方向，想换模型，想补上下文，也在这里完成。还能新建任务，让它在已经连好的开发环境里开工。

用之前要满足几个条件

手机上装好 ChatGPT App 并更新到最新版，电脑上装好 Codex 桌面 App，同样更新到最新版。

两边登录同一个 ChatGPT 或者 OpenAI 账号，而且账号所处的地区和套餐在支持范围内。

电脑那边的 Codex 得已经连上项目，或者正在一台已授权的机器、devbox 或者远程环境里跑着。

还有一个容易忘的地方。任务如果会写文件、跑命令或者访问网络，该确认的权限一样要确认，连了手机不等于权限自动放开。

什么时候用最合适

手机端解决的是离开电脑但不想让任务停住这件事。

通勤路上看一眼长任务跑到哪了。它需要你拍板选方案的时候快速给个方向，任务卡在权限审批上顺手批一下。会议前让它把最新的代码、issue 和文档汇总出来。突然想到一个改动点，先发过去让它开始探索，回电脑再看 diff。

什么活别在手机上做

手机代替不了本地完整审查。大范围代码合并前的最终 review，还是回电脑上做大屏看。

涉及生产环境、密钥、账单和发布部署的高风险操作，别在手机上点头。

需要长时间读大量 diff 的任务，手机的屏幕撑不住。需要手动操作 IDE 和调试器这类本机界面的活，也一样得回电脑。

一次典型流程

在电脑上打开 Codex 桌面 App 进入对应项目，让它开始一个跑得比较久的任务，比如排查失败的测试或者整理文档。

然后人离开电脑。在手机 ChatGPT App 里进 Codex，找到同一个正在跑的线程，看它的输出和截图，还有终端日志、测试结果和 diff。它需要确认的时候，直接在手机上回复、审批或者调整方向。

回到电脑之后再做完整 diff review，跑验证命令，然后提交。

它和 Codex Cloud 不是一回事

两者都能离开电脑，但任务跑的地方不一样。

手机端连的是你自己的电脑，也可能是 devbox 或者远程环境。文件和凭据都留在原机器上，适合跟进本地长任务，做审批，看结果。Codex Cloud 跑在云端环境里，依赖的是云端连接的仓库和授权，适合那种不依赖本地电脑的仓库任务。

手机端能不能一直用，还得看网络。Cloud 这边没这个顾虑。
