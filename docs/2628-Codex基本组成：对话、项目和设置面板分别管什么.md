# Codex 基本组成：对话、项目和设置面板分别管什么

> 原文链接：[https://www.sz003.com/jiaocheng/2628](https://www.sz003.com/jiaocheng/2628)

第一次打开 Codex 桌面端，左边栏就两个东西，Chat 和 Project。剩下的藏在对话框和设置面板里，认一遍就知道该点哪儿。

两个入口：Chat 和 Project

Chat 跟 ChatGPT 网页版差不多，随手问问题用。每个对话之间互不相干，也不共享文件夹，聊散了不影响别的。

Project 是动本地文件的地方。写代码，改文档，做 PPT，都走这里。一个项目里的所有对话共用同一个文件夹，文件都在一处，管理起来不乱。在项目里下的指令，改的是你本地文件夹里真实的文件。

对话框上那几个按钮

对话框的样子跟 ChatGPT 网页版接近，有四个地方不一样。

需要让它看着某份材料干活，就在添加上下文那里附上文件、截图或者别的参考内容。

不同任务对模型的要求不一样，这里可以随时切。

权限控制是给自己留后路的一项，默认跑在沙盒里，需要它碰沙盒外的东西时才往上放。

最后一个是工作目录，指定它在这个本地文件夹下执行任务。

Skills 和插件

官方默认带了一批技能。Skills Creator 用来造新技能，Skills Installer 用来装技能，OpenAI Docs 用来查最新官方文档。在对话框里打一个 $ 就能把技能叫出来。

插件是外部工具的入口，里面可能还包着技能、MCP 和脚本。常见的有 Computer Use 和 Browser Use，做幻灯片的 PPT，写文档的 Docs，处理表格的 Excel。Slack 和 GitHub 也在里面。有些插件要额外配置才可用。

自动化

自动化适合那种每天都要做一遍的活。给它一条命令，指定工作树，项目地址，还有执行间隔，它自己按点跑。

要注意的是自动化跑在默认沙盒里。涉及工作目录外的文件，访问网络，操作电脑应用，这几类操作它会直接失败。想让它跑通，得在规则里单独放行。

设置面板

设置面板在左下角，点头像或者那个齿轮图标就打开了。左边一列菜单看着挺多，实际大部分保持默认就行，都是按需才开。

有几个开关先别急着打开

最容易手快打开的是这么几个。完全访问权限算一个，浏览器控制和电脑操控算一类，钩子和 MCP 服务器也算一类。它们的共同点是权限很大，建议按任务一个一个开，别一次全开。

完全访问权限放开了，Codex 就能碰沙盒外的文件和环境变量，只在确实需要的时候临时开，比如要用 computer use。电脑操控会直接接管你的鼠标键盘，它干活的时候你最好别动电脑。钩子是在 Codex 的生命周期事件里跑自定义脚本，一般用来做日志，记忆整理，验证检查，默认不用配。MCP 服务器是给它接外部工具和上下文，比如文档，浏览器，设计工具，等项目真的需要再接。

权限这块有三个档。默认档跑在沙盒里，安全，但访问工作目录外的文件和改本机环境变量这类操作会被拦住。中间那档叫自动审核，也叫替我审批，越权的命令如果模型判断安全，可以自己往下走，不用你点确认。最后那档就是完全访问。

其他几个常用的设置

工作模式分编程和日常工作两种。编程模式保留更多技术细节，日常模式更松，问答、整理和写作这类活更顺手。

模型生成速度默认标准就够了。快速模式会消耗更多配额，Pro 5x 以上的套餐才推荐开。

Git 那一栏管的是提交习惯，分支前缀，合并方式，要不要草稿 PR，保持默认也能用，等你对流程有想法了再改。

工作树是给多个任务各准备一块独立工作区。同时修不同问题，比较不同方案的时候顺手，用之前先确认改动已经保存或者提交。

环境这一栏是告诉 Codex 你的项目怎么构建怎么跑。装依赖，起开发服务器，跑测试，这几条命令都配在这儿。手上有项目要反复打开的话，配一次能省不少事。

收尾

设置项的名字会跟着版本变，看到跟截图对不上，先翻 OpenAI 官方的 Codex App 文档。日常用不到这么多，先把 Chat 和 Project 两个入口用顺，剩下的遇到问题再进来翻。
