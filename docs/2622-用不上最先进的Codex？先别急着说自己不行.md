# 用不上最先进的 Codex？先别急着说自己不行

> 原文链接：[https://www.sz003.com/jiaocheng/2622](https://www.sz003.com/jiaocheng/2622)

刷到别人用 Codex 干活，一趟一趟地出活，自己连入口都没摸到。第一反应往往是同一个，是不是我太菜了。

先别急着下这个判断。有个特别老套的类比，放在这儿刚好合适。

电脑上装了个 360，用着别扭，随手就卸得干干净净，说明什么，说明你根本不需要它。反过来，有人卸了又装，删完自己又下回来，来回折腾好几轮，那才是真离不开它的。

Codex 这件事，道理一样，只是方向要倒过来看。

能自己找到路子用上 Codex 的人，网络环境会调，配置文件会改，注册账号也难不倒。这种人手里从来不缺工具，Codex 只是工具箱里的一件备选，今天不用，明天换一个照样干活。他用得上，但说不上多依赖。

真正卡在外面的人，登不上，装不明白，用着还老出状况，急得团团转。表面看是输在了门槛上。可换个角度，一个人这么较劲也要够到它，恰恰说明他缺一件趁手的工具，缺到愿意为它一遍遍碰壁。

所以卡在外面这件事，只有两种解释。你不缺它，或者你正缺它。没有一种叫我不行。

想通这一点，心里那点焦虑能消掉一半。

接下来该问的是另一个问题，你要的到底是 Codex，还是那件能把活干漂亮的好工具。

卡在这里的人不少。他们把工具本身当成了目的，觉得手上没有最先进的那个，活就干不漂亮。真把这个问题摊开看，多数人真正在意的是代码能不能跑通，方案能不能落地，明天要交的活能不能按时交出去。背后跑的是哪家的模型，其实没那么要紧。

国产的 AI 工具这一代，接住日常工作完全够用。写文档，做分析，搭个小工具，打开就能上手，也没有那道折腾半天的门槛。

工具是追不完的。今天最强的那个，过三个月可能就排不上号。你亲手做出来的东西，才会一直跟着你。

等哪天你被手上的工具真正卡住，怎么绕都绕不过去，那时候再去找更先进的，路自然会出现在你面前。到那天，你是带着一堆具体问题去找它的，不是带着焦虑。

先把手上那件拖了好几天的活，用现在这台机器干完。
