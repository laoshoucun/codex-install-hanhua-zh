# Codex Cloud 怎么用：不装客户端，让它在云端干仓库的活

> 原文链接：[https://www.sz003.com/jiaocheng/2642](https://www.sz003.com/jiaocheng/2642)

前面几种用法都要在你自己电脑上跑。Cloud 是另一条路，不装客户端，打开浏览器连上 GitHub 仓库，任务在云端完成。

它适合什么时候用

跑得比较久，又不想占本地资源的活。多个任务要同时推进的活。让它在独立环境里分析仓库、提出 PR。还有不在电脑旁、手边只有浏览器的时候。

三步跑起来

第一步是打开 ChatGPT 里的 Codex Cloud 页面，连上之后会跳到任务页。

第二步要授权仓库。Cloud 直接在 GitHub 仓库里跑，先得把授权做掉。你可以授权全部仓库，也可以只挑其中几个。

第三步是下指令。指令发出去它在云端执行，进度显示在页面下方的任务列表里。点开某个任务能看到每一步的执行过程和中间状态，任务结束后也能看到最终的回答和产出内容。

和桌面端怎么分工

两者的运行环境不一样。桌面 App 跑在你自己的电脑上，要先装客户端，适合本地代码和插件，还有自动化这几类活。Cloud 跑在 GitHub 的云端环境，浏览器直接访问，适合远程仓库分析和 PR 生成这类活。

并行任务两边都支持。判断方式很简单，这活离得开你的电脑就丢 Cloud，离不开放本地。
