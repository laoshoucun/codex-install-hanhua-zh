# Codex 可用技能榜第10期：前十名七个在做视频和图

> 原文链接：[https://www.sz003.com/chajian/2698](https://www.sz003.com/chajian/2698)

这周的 Codex 可用技能指数榜出到第10期。榜首 image-to-video，指数16615，把静态图片生成视频。第二名 seedance-2-5-image-to-video，16615，同一件事换 Seedance2.5 的模型再做一遍。第三名 ai-image-generation，16575，生成和编辑图片。

光看前三还不觉得，往下数就看出形状了。前十名里跟视频沾边的有六个：第五名 wan-3-0-prime-reference-to-video，拿参考素材生成视频，16552；第七名 video-edit，智能匹配模型编辑视频，16489；第九名 seedance-2-5-reference-to-video，参考图生成视频，16443；第十名 ai-video-generation，16437，名字最直白，生成 AI 视频。再加上第三名的图和第八名 ai-music 的音（通过 CLI 生成 AI 音乐，16478），十个名额里八个在干视听的活。

剩下两个位置，一个是第四名 design-mobile-apps，16561，设计移动应用与 UI；一个是第六名 reddit-automation，16535，发现 Reddit 需求并起草回复。跟写代码直接相关的技能，一个都没挤进前排。

这份榜传开之后，问的人不少。有人第一反应是懵的，Codex 什么时候能生成视频了。有人较真，说排在前面的居然不是 vibe coding 那种写代码的活。有人翻来翻去找生成 PPT 的技能，还有人问 video-edit 从哪里进。更实在的问题是钱，这些技能是不是都得开会员才能用，一句全要钱把大头的心声说完了。

回到用的人这边，榜单怎么看不重要，怎么用才重要。

第一，别按指数装技能。指数高说明用的人多，不代表跟你的活有关。你手头要写代码，design-mobile-apps 和 reddit-automation 就比榜首的 image-to-video 对你有用。

第二，视听技能基本都要会员或者按量扣费，用之前先算成本。真有做视频的需求，先拿 image-to-video 小量试，效果对路再加量，别一上来就把额度烧在试错上。

第三，找技能别只盯着榜。有人照着榜上的名字去搜，搜到第二个就断了，多半是搜索词不对。按功能描述去筛，比记名字快。

工具还是那个工具，用的人已经把它当内容生产机了。风向这事，榜单比文章诚实。
