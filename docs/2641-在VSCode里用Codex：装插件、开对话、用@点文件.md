# 在 VS Code 里用 Codex：装插件、开对话、用 @ 点文件

> 原文链接：[https://www.sz003.com/jiaocheng/2641](https://www.sz003.com/jiaocheng/2641)

如果你本来就整天待在编辑器里，为 Codex 单独切到桌面 App 反而多一道手续。VS Code 插件能让你在写代码的地方直接把它叫出来。

装插件

VS Code 左边栏有个扩展图标，搜 Codex，第一个结果就是，点安装。

装上的是 OpenAI 官方发布的 ChatGPT 插件，Codex 的对话和代码辅助能力都集成在里面。

打开对话窗口

随便打开一个项目文件，右上角会出现 ChatGPT 的图标。点它，右边栏就展开 Codex 的对话窗口。

用 @ 直接点文件

窗口打开之后直接输入需求，它就开始干活，用法和桌面 App 基本一致。

有一个操作值得专门练一下：在对话框里打一个 @，然后挑具体文件。它会直接定位到那个文件去分析或修改，比让它自己全局搜索更快也更准。任务目标明确的时候，优先用 @ 把相关文件点出来。

它和桌面 App 怎么选

两者的差别主要在你要同时管几件事。

桌面 App 适合多任务管理，Skills 和 Automations 也在那边，不过看文件结构要切界面，改动前后的对比也得单独看。

VS Code 插件贴近编辑器的工作流，文件结构直接在编辑器里看，改动前后的差异能结合编辑器自带的 diff 一起看，日常写代码的人用着顺手。

两者不冲突，配合着用就行。
